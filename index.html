Build the library the right way

1. Find rights-cleared films

Start with public-domain films after verifying the specific version, or independent filmmakers who grant written streaming and download permission.

2. Add verified video links

For each title, record its source, licence, streaming URL, download permission and any attribution requirements.

3. Launch and improve

Publish the website, test it on phones and computers, then add user accounts and app features when the project is ready.
